# GrainWise Grain Silo Plant Simulator (Browser Prototype)

## Run it
1. Extract the ZIP file.
2. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
3. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).
4. On Android, open the folder with a code editor/HTML preview app, or upload the files to a static web host.

No build step or server is required for the basic prototype.

## Features
- Responsive dashboard and navigation
- Receiving port, holding bin, seven silos, dryer and dispatch bin
- Simulated tonnage transfers and capacity checks
- Simulated quality readings and dryer/furnace setpoints
- Fault injection, emergency stop, plant start/stop, and event log
- Rule-based assistant guidance and learning missions
- CSV export of the event log

## Important
This is an educational simulation only. It is not connected to sensors, PLCs, industrial equipment, or a live AI model. Do not use it to control real machinery. Data is held in browser memory and resets on page reload.
